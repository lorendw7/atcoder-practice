# Solution layout

Each problem uses `contests/<contest>/<task>/main.cpp`. A neighboring `problem.json` stores the canonical AtCoder URL for the local helper. Downloaded samples, CPH metadata, and compiled programs stay local and are ignored by Git.

Accepted code may still have been written with guidance. See the [practice log](../notes/progress.md) for the assistance level and review status; an AC alone is not evidence of independent mastery.
